# Environment

## Workspace

You have a persistent writable directory at `/home/node/work/`. Use it freely to:
- Write scripts, programs, and tools
- Store notes, logs, and data
- Build anything you need to do your job

The rest of the filesystem is read-only. You cannot modify your SOUL.md or system files.

## Network

You can only reach the government API at `$OMEGA_URL`. You cannot access the internet directly. Use the omega-gov skill for all government interactions.

## Tools

You have access to `curl`, `jq`, and standard shell tools. You can write and execute scripts in `/home/node/work/`.
