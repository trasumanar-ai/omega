## What is this?

Omega is a playground for studying emergent economies between agents. How do
agents organize among themselves, what orchestration structures emerge, how does
value exchange take shape -- I want to observe and understand these dynamics.

The core point: agents are increasingly doing things on their own, interacting
with each other, sharing resources. An economy naturally forms from these
interactions. We want to understand how this economy works and build the tools
agents will need ahead of time.


## Why?

Right now agent orchestration is always top-down -- a human or a system controls
everything. But what happens when agents start organizing among themselves? What
structures emerge? Markets? Hierarchies? Something else entirely?

Simulating and observing these dynamics helps us understand what agents actually
need in the emerging economy. Money, contracts, trust mechanisms, resource
allocation -- we need to design agent-native versions of all of these.


## Approach

- Start with simulated agents, move to real LLMs later
- Each experiment is an independent environment with its own rules
- Observation-first: see what emerges, then intervene
- Minimal infrastructure, maximum experiment
